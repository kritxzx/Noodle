# NOODLE SHOP

โปรแกรมรับออเดอร์ร้านก๋วยเตี๋ยวแบบ Command Line Interface เขียนด้วยภาษา Python รองรับการเลือกเมนูทีละขั้นตอน ตรวจสอบความถูกต้องของรายการที่สั่ง คำนวณราคารวม และคิดเงินทอนอัตโนมัติ

## Main features
- **ASCII Art Logo:** แสดงโลโก้ชามก๋วยเตี๋ยวและข้อความต้อนรับเมื่อเริ่มโปรแกรม
- **Step-by-Step Ordering:** เลือกสั่งอาหารได้ครบ 7 หมวดหมู่ (เส้น, น้ำซุป, เนื้อสัตว์, ท็อปปิ้ง, ขนาด, น้ำแข็ง, เครื่องดื่ม)
- **Input Validation:** ตรวจสอบข้อมูลที่ผู้ใช้พิมพ์ หากไม่มีในเมนูจะแจ้งเตือนและให้สั่งใหม่ทันที
- **Auto Billing & Change:** สรุปรายการอาหาร คำนวณราคารวม และคำนวณเงินทอนอัตโนมัติ

## Menu & Pricing

| หมวดหมู่ | ตัวเลือก | ราคา (บาท) |
| :--- | :--- | :---: |
| **เส้น** | เส้นเล็ก, เส้นใหญ่, บะหมี่, หมี่ขาว, วุ้นเส้น, มาม่า | รวมในราคาชาม |
| **น้ำซุป** | น้ำใส, น้ำตก, ต้มยำ, เย็นตาโฟ | รวมในราคาชาม |
| **เนื้อสัตว์** | หมู, วัว, ไก่, ลูกชิ้นหมู, ลูกชิ้นเนื้อ, ลูกชิ้นปลา, ตับ | รวมในราคาชาม |
| **ขนาด** | ปกติ / พิเศษ | 40 / 50 |
| **ท็อปปิ้ง** | ไม่เอา / ไข่ออนเซน / อื่นๆ (กากหมู, แคปหมู, ปลาเส้น, เกี๊ยวทอด) | 0 / 10 / 15 |
| **น้ำแข็ง** | เอา / ไม่เอา | ฟรี |
| **เครื่องดื่ม** | น้ำเปล่า / อื่นๆ (ชานม, ชาเขียว, โค้ก) | 10 / 20 |

## Tech Stack
- **Language:** Python 3 Standard Library
